The module is split into a single React page component and two pure utility modules. `LocationsPage.tsx` is the entry point: it reads location/document state from `ArchiveContext`, renders a responsive split layout (left tree explorer, right detail inspector), and owns all modal state for create/edit/delete/QR/photo operations. Tree traversal and document scoping are delegated to `locationUtils.ts`, which provides pure functions (`getChildrenLocations`, `getAllDescendantIds`, `getLocationAncestors`, `calculateLocationPath`, `getDocumentsInLocation`) that operate on flat `LocationItem[]` arrays using `parentId` links. Image resolution is isolated in `locationImages.ts`, which maps each `LocationType` to a default image URL and exposes `getLocationImage` so the page never hard-codes asset paths. The page composes shared UI primitives (`PhotoUploader`, `QRBarcodeModal`, `ConfirmModal`, `StatusBadge`, `LocationPathBreadcrumbs`) and Lucide icons; it depends outward only on `../context`, `../components/common`, `../types`, and these two local utils — no reverse dependencies exist.
