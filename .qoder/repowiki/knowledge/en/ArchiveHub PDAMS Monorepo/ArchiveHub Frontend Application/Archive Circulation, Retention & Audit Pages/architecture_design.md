Three sibling React functional components (`CheckoutsPage`, `RetentionPage`, `AuditLogsPage`) under `src/pages/` that act as read-only or action-oriented UI views over a single source of truth provided by `useArchive()` from `../context/ArchiveContext`. Each page consumes only the slices it needs: `CheckoutsPage` reads/writes `checkouts`, `documents`, `locations` and invokes mutation actions like `approveCheckout`, `rejectCheckout`, `processCheckoutDispatch`, `processCheckInReturn`; `RetentionPage` reads `documents` and `documentTypes` to compute expiry windows; `AuditLogsPage` renders the `auditLogs` array with local client-side filtering. Shared presentational primitives (`StatusBadge` from `../components/common/StatusBadge`) and Lucide icons are reused across pages. There is no internal routing or API layer — these pages are leaf view components consumed by the app's router and depend exclusively on the global context for data and side effects.
