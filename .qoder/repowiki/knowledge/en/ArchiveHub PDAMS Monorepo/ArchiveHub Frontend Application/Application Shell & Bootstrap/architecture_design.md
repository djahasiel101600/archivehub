- `src/main.tsx` is the Vite entry point: it mounts the root DOM node via `react-dom/client`'s `createRoot`, wraps `<App />` in React StrictMode, and imports the global stylesheet.
- `src/App.tsx` defines the app shell: `AppContent` reads routing state (`activeTab`, `isAuthenticated`) from `ArchiveContext`, guards unauthenticated users by rendering `AuthPage`, and otherwise renders a responsive layout composed of `Header`, `Sidebar`, `MobileBottomNav`, and a `<main>` viewport that conditionally mounts one of seven page components (`DashboardPage`, `LocationsPage`, `DocumentsPage`, `DocumentDetailPage`, `CheckoutsPage`, `RetentionPage`, `AuditLogsPage`, `SettingsPage`) based on `activeTab`. Global UI state (selected document ID, mobile drawer open flag, scanner modal visibility, trigger flags for opening modals directly) lives in this component and is passed down as props to child pages and the `CameraQRScannerModal`.
- `src/index.css` is the single global stylesheet; it imports Tailwind CSS v4 via `@import "tailwindcss"` and adds a `@media print` block that hides chrome and exposes printable areas.
- Dependency direction is strictly inward: this module depends only on sibling feature modules (`context/`, `components/layout/`, `components/scanner/`, `components/auth/`, `pages/*`) and exposes no public API — it is the composition root consumed by `main.tsx`.
