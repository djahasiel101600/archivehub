The root wires the two runtime halves together: `server.ts` boots an Express app on port 3031, runs DB migrations and seed via `src/db/migrate.js` and `seed.js`, mounts REST endpoints under `/api/*` that delegate all persistence to `src/db/repository.js`, and in development injects Vite's middleware (`vite.config.ts`) for HMR while serving the built `dist/index.html` in production. The frontend (React + Tailwind) is configured through `vite.config.ts` with a `@/` path alias pointing at the repo root so both client and server resolve shared paths identically. On startup the server checks PostgreSQL health; if unavailable it falls back to memory mode so the app stays runnable without a database. Scripts in `package.json` orchestrate the full lifecycle: `dev` runs `tsx server.ts`, `build` compiles the frontend with `vite build` then bundles the server entry with esbuild into `dist/server.cjs`, and `start` launches the compiled server.
