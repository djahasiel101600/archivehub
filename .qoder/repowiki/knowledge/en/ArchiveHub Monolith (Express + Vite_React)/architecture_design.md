The root `server.ts` is the sole process: it boots Express, checks PostgreSQL health, auto-runs migrations and seed via `src/db/migrate.js` / `seed.js`, mounts every `/api/*` route, delegates all persistence to `src/db/repository.js`, and in development injects Vite's middleware for HMR while serving `dist/index.html` as a static SPA in production. The frontend (`frontend_app`) is built by Vite into `dist/` and consumed by the same server, so client and server share TypeScript path aliases configured in `vite.config.ts`. Mutating routes accept a `user` object in the request body to propagate actor identity through repository calls for audit logging, and on startup if PostgreSQL is unavailable the server falls back to memory mode so the app stays runnable without a database.
