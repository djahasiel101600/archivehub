The app is bootstrapped by `src/main.tsx` → `App.tsx`, which wraps the tree in `ArchiveProvider` from `context/ArchiveContext.tsx`. `AppContent` owns global UI state (`activeTab`, selected document, scanner modal flags) and renders a responsive layout composed of `Header`, `Sidebar`, `MobileBottomNav`, and a `<main>` viewport that switches between page components based on `activeTab`. Pages are grouped by domain: `pages/LocationsPage*` for physical storage hierarchy, `pages/DocumentsPage*` + `DocumentDetailPage` for document registry, and `pages/CheckoutsPage`, `RetentionPage`, `AuditLogsPage`, `SettingsPage` for circulation, retention policy, and audit. Cross-cutting concerns live in sibling directories: `auth/` provides session and API guards consumed by pages/components, `components/common/` supplies reusable modals/badges, `components/documents/` and `components/scanner/` provide feature-specific modals (including the new batch QR relocate workflow), `db/` exposes the SQLite schema/repository layer used by all pages, and `utils/` holds shared helpers (barcodes, printing, location images). The AI suggestion module under `ai/` plugs into the document workflow via `suggestBundle.ts`. New tabs/pages are added by importing the page component and adding a case to the `activeTab === '...'` switch inside `AppContent`.
